How to install:

1. Clone this repo on your machine: <br />
 ```Git clone https://github.com/Jake-Hines/Gizmos.git```

2. Copy the folder ```JakeHines``` to your own .nuke folder

3. The structure should be:
```
.nuke/
├── init.py
├── ...
└── JakeHines/
    ├── AutoKey_Keymix/
    ├── Jake_Hines_Icon.png
    ├── menu.py
    └── init.py
```
4. Have your nuke see my setup: <br />
Add this line to the ```.nuke/init.py``` folder: <br />
```nuke.pluginAddPath("./JakeHines")```

Restart Nuke and it should be their on your menu with my goofy logo
